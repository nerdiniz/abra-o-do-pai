**Abraço do Pai** é uma aplicação católica completa desenvolvida para auxiliar fiéis em sua jornada espiritual diária. Com um design moderno, sereno e focado na experiência do usuário, o aplicativo reúne ferramentas essenciais de oração, liturgia e comunidade em um único lugar.

## ✨ Funcionalidades Principais

### 📿 Vida de Oração
- **Santo Terço Interativo**: Guia passo a passo para todos os mistérios (Gozosos, Dolorosos, Gloriosos, Luminosos). Detecta automaticamente o mistério do dia, conta as Ave-Marias e registra seu progresso espiritual.
- **Catálogo de Novenas**: Mais de 50 novenas completas (S. Judas, N.S. Desatadora, S. Miguel, etc.) com todos os textos de oração disponíveis offline. Acompanhe o progresso diário (Dia 1/9) e defina intenções pessoais.
- **Vela Virtual**: Acenda uma vela virtual com uma intenção específica. A vela permanece "acesa" com um contador em tempo real, simbolizando sua oração contínua.

### 📖 Liturgia e Estudo
- **Liturgia Diária**: Leituras da missa (1ª Leitura, Salmo, Evangelho) atualizadas diariamente. Possibilidade de navegar por datas passadas ou futuras.
- **Diário Espiritual**: Um espaço seguro e privado para registrar reflexões, graças alcançadas e pedidos de oração. Seus dados são salvos na nuvem.
- **Exame de Consciência**: Guia prático para preparação para confissão, baseado nos 7 Pecados Capitais e nos 10 Mandamentos.

### 🤝 Comunidade e Serviço
- **Pedir Auxílio**: Canal direto para fiéis solicitarem ajuda espiritual (aconselhamento, unção) ou material.
- **Painel do Sacerdote**: Perfil exclusivo para padres visualizarem e atenderem pedidos de ajuda da comunidade, com sistema de gamificação "Nível de Caridade".

### ⚙️ Personalização e Tecnologia
- **Dashboard Unificado**: Visão geral do seu dia com gráfico de "Progresso Diário" e tarefas sugeridas (reze o terço, continue sua novena).
- **Perfil Completo**: Gestão de sacramentos recebidos, datas importantes e dados pessoais.
- **Modo Escuro**: Tema totalmente adaptável (Claro/Escuro) para conforto visual em qualquer horário.
- **PWA (Progressive Web App)**: Instalável no celular como um aplicativo nativo, funcionando offline e com alta performance.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com uma stack moderna focada em performance e escalabilidade:

- **Frontend**: React 18, TypeScript, Vite
- **Estilização**: Tailwind CSS, Lucide React (Ícones)
- **Backend (Baas)**: Firebase Authentication, Cloud Firestore
- **Visualização de Dados**: Recharts
- **Hospedagem**: Vercel

## 🚀 Como Executar o Projeto

Certifique-se de ter o **Node.js** instalado em sua máquina.

1. **Clone o repositório**
   ```bash
   git clone https://github.com/seu-usuario/abraco-do-pai.git
   cd abraco-do-pai
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Configure as Variáveis de Ambiente**
   Crie um arquivo `.env` na raiz do projeto e configure suas chaves do Firebase (utilize o `.env.example` como base).

4. **Execute localmente**
   ```bash
   npm run dev
   ```

O aplicativo estará disponível em `http://localhost:5173`.
